# Manual verification checklist

Host code (lib/) reloads live with `plugin_manager set_plugin include:linked-workspace-ui`; client changes load with **应用 → 重新加载界面** (a full restart is only needed after re-installing the package). Then verify:

## 设置 → 连接

1. 左下角「账号菜单」→ 设置 →「连接」。
2. 页面：标题、编辑器主题卡片（10 套，点击立即切换，编辑器配色跟随）、联动工作区组、远程目录组。
3. 添加远程目录：选 `RTX-PRO-6000-1`，路径 `/shared_data_ssd1/huangjh` → 卡片出现；「测试」显示延迟。
4. 添加联动工作区：
   - SSH 连接 + 远端目录（浏览），本地目录（浏览/新建文件夹/系统选择器），镜像可选，名称可选；
   - 创建后：本地目录出现 `.local/linked.json`、`.local/session/`；镜像开启时还有 `.remote/`；
   - DSH 左侧工作区列表出现新工作区，标题**不带** `⇄`，行首图标是链环（不是文件夹）；
   - 设置页联动卡片显示本地 ⇄ 远端路径、镜像开关、「同步」。
5. **后台同步**：镜像默认关闭；打开镜像开关后立即开始一次后台检查，之后每约 5 分钟自动检查远端与 `.remote` 的差异（下载变更、删除多余镜像、跳过未变更文件）。点「同步」→ 立即显示「同步中：N 个文件 / X KB」与「取消同步」，超过 60 s 也不会报超时；完成后显示「同步完成：N 个文件」，`.local/mirror-manifest.json` 更新。关闭镜像会取消进行中的任务，两侧允许有差异。
6. 主题模式：默认选中 **系统**（跟随 DSH 浅色/深色）；三张模式卡无预览条；「指定主题」共 9 张家族卡（GitHub/Solarized/One/Dracula/Monokai/Nord/VS Code/Xcode/Catppuccin），每卡同时有浅色/深色版本；切模式卡后同一批卡片预览在浅色/深色间切换，编辑器配色同步。
7. 打开方式：右侧栏工具栏「打开选项菜单」→ 编辑器 / 系统默认应用 / 复制路径；选择后 `settings.get` 返回 `fileOpenMode` 对应值，下一次点击文件按该方式处理。

## 左侧「添加工作区」

1. 点左侧工作区标题栏的「+」→ 弹窗出现「本地文件夹 / 联动工作区」两个页签。
2. 本地页签：浏览目录、新建文件夹、系统选择器、「使用此目录」→ DSH 工作区创建并选中。
3. 联动页签：填写主机/远端目录/本地目录 → 创建后工作区出现在左侧，行图标为链环；弹窗关闭。
4. 已有旧工作区若标题仍带 `⇄ `：Host 启动约 1 s 内自动去掉前缀（`linked.list` 的 `workspaceTitle` 同步更新）。

## 远程只读与打开跳转

1. 打开远程目录中的非空文本文件：应看到行号、代码内容与底部「只读」状态，不能编辑；空文件保持空白。
2. 设置 → 连接点击联动工作区「打开工作区」：设置关闭并跳转到该联动工作区的会话。
3. 设置 → 连接点击远程目录「打开」：设置关闭并打开对应远程目录标签。

## 本地工作区浏览

1. 添加工作区 → 本地工作区：本地目录只显示输入框和「浏览…」按钮，不默认展开目录树。
2. 点「浏览…」展开选择器，选中目录后选择器收起、路径写回输入框。
3. 设置 → 连接顶部不再出现「打开右侧栏」。

## 添加按钮位置

1. Ctrl+O / 添加工作区 → 联动工作区：表单内部不再有取消/提交按钮，底部为「取消 + 创建」。
2. 设置 → 连接按钮显示「创建联动工作区」，表单标题为「创建联动工作区」，底部按钮为「创建」。
3. 设置 → 连接 → 添加远程目录：底部提交按钮为「添加」。

## 本地工作区

1. Ctrl+O / 添加工作区弹窗第一页签显示「本地工作区」。
2. 该页签下有「1. 本地目录」（可用 C:/D:/E: 盘符切换）和「2. 工作区名称」。
3. 选择目录、填写名称后点「创建」，DSH 工作区列表出现该本地工作区（名称按填写值）。

## 添加工作区表单

1. 设置 → 连接点击「添加联动工作区」：打开的表单中不再出现「远程目录/联动工作区」切换，直接显示远程+本地路径与名称。
2. 设置 → 连接点击「添加远程目录」：表单不显示联动切换，也不显示「工作区名称」字段，直接创建。
3. Ctrl+O / 添加工作区弹窗切到联动工作区时，内部同样不再出现远程目录切换。

## 双向传输与本地盘符

1. 在联动工作区选中一个**本地**文件/文件夹，点「传输所选文件/文件夹」：远端对应相对路径出现副本。
2. 选中一个**远端**文件/文件夹点传输：只出现在本地 `.remote/`。
3. 新建联动工作区后，本地目录不应自动出现 `.local` 或 `.remote`（除非启用镜像同步/执行传输）。
4. 添加本地工作区或联动工作区时，本地目录浏览器的 C:/D:/E: 盘符按钮可切换到非 C 盘；远程面包屑只显示一个前导斜杠。

## 右侧栏入口

1. 在**非联动**本地工作区的会话打开右侧栏开始页：不应出现「联动工作区目录」。
2. 在联动工作区的会话打开开始页：应出现「联动工作区目录」，点开后只显示该会话绑定的联动工作区（不是别的联动工作区）。
3. 在设置 → 连接添加一个远程目录后，任意工作区会话的开始页都出现「远程目录」；打开后只读（可展开、查看文件、下载、复制路径、属性），不能编辑/传输/重命名/删除。

## 右侧栏「联动工作区目录」

1. 会话标题栏「打开右侧边栏」→「+」→「联动工作区目录」；旧标签页刷新后标题也会自动改成该名字。
2. 面板：右侧固定目录面板包含**上方「远程目录」、下方「本地目录」**；工具栏的面板按钮可开/关整个目录面板。中间是文件内容面板；未打开文件时显示「打开文件 / 从工作区目录树中选择文件」。本地树默认隐藏 `.local`/`.remote`，开「显示隐藏文件」后可见。
3. 展开工作区 → 目录树懒加载；文件行有按类型区分的彩色图标（.py/.ts/.json/.md/.png 等）。
4. **单击**文件夹立即展开/折叠；**单击**文件在中间内容面板打开；单击另一个文件会替换未固定的预览标签。**双击**文件固定标签，之后单击其他文件不会覆盖；双击文件夹保持展开。目录面板保持最右侧可见。本地文件标签不显示图标，并且可在内容面板中编辑保存。
5. 工具栏「切换文件树」：所有文件 / 已更改的文件 / 所有更改；远端仓库（如 nsl-wp）应列出 `git status` 修改与未跟踪文件，本地非 git 目录提示「该目录不是 Git 仓库」。
6. 工具栏「在文件中搜索」：输入 `paradis` → 结果按「远程目录/本地目录」分组，点击结果打开文件；清空/关闭后回到原树。
7. 工具栏「打开选项菜单」：编辑器 / 系统默认应用（远端文件下载到临时目录并用本机默认应用打开）/ 复制路径（剪贴板得到远端绝对路径）。
8. 刷新按钮：目录、git 状态与搜索重新加载。
9. **多标签/固定**：单击文件 A → 预览标签；单击文件 B → A 被替换为 B；双击 B → B 固定；再单击文件 C → B 保留且新增 C 标签。重复点击已打开文件聚焦原标签；关闭一个标签后其槽位可复用（最多 12 个）。
10. **关闭未保存文件**：修改文件但不保存（关闭自动保存时），点标签上的 × → 出现「保存 / 放弃 / 取消」；点取消留在编辑器，点放弃关闭，点保存先写盘再关闭。
11. **快捷键**：`Ctrl+S` 保存；`Ctrl+W` 关闭当前标签（未保存时弹窗）；`Ctrl+Tab` / `Shift+Ctrl+Tab` 切换标签；`Ctrl+B` 显示/隐藏目录面板；`Ctrl+Shift+F` 打开文件搜索。
12. **终端按钮**：远程树工具栏的终端按钮打开外部终端并自动 `cd` 到当前远程根目录；联动工作区的本地按钮打开本地终端并 `cd` 到本地目录。远程终端需使用系统 `ssh`，首次可能要求确认主机指纹/输入密码。
13. **自动保存**：设置 → 连接 →「编辑器行为」开启自动保存 → 修改文件后停止输入约 1 秒应自动写盘、灰点消失；关闭自动保存后再修改，不应自动写盘，`Ctrl+S` 才保存。设置重载后开关状态保持。
14. **传输按钮**：在树中选中远端文件/文件夹（行高亮），点工具栏传输按钮 → `.remote/` 出现对应文件；右键「队列」可看到排队/传输中/完成状态。
15. **显示隐藏文件**：打开目录时默认显示 `.git`、`.gitignore`、`.local`/`.remote` 等隐藏项；点眼睛按钮可隐藏，再点恢复。目录面板默认开启。
16. **右键菜单**：文件/文件夹/根节点右击 → 传输、下载到默认文件夹、队列、打开、用记事本编辑、复制、粘贴、复制路径、重命名、删除、更改权限、新建（文件夹/文件）、属性；在远端与本地两侧各验证一次重命名/删除/新建/属性。
17. **运行中图标**：在该联动工作区的会话里发起一轮对话，运行期间左侧工作区的链环图标应变蓝；结束后（约 5 秒内）恢复原色。
18. **本地技能**：在联动工作区会话里让模型列出本地技能（或调用 `linked_skills` list/read）；应能读到本机 `~/.dsh/skills` / `<local>/.dsh/skills` 下的 SKILL.md，且无需在远端安装；`skills.list` API 返回非空。
19. 编辑器：内部内容面板不显示路径/保存头部（Ctrl+S 保存）；修改未保存时文件标签名前出现灰色圆点；行号、语法高亮（字符串/注释/关键字有颜色）、主题配色、
   远端并发修改 → 冲突提示（重新加载/强制保存）、二进制/大文件只读；底部状态栏完整可见（不再被视口裁切）。

20. **右键新建回归**：远端目录和本地目录的文件夹均右击后，菜单中直接出现「新建文件夹」「新建文件」（不依赖向右展开的子菜单）；分别在根目录和嵌套目录创建文件夹、`.txt`、`.csv`、`.html`、`.svg`、`.png`，应创建空普通文件。`.md`、`.pdf`、`.docx`、`.xlsx`、`.pptx` 仍创建对应模板并打开；重复名称应留在命名对话框并显示错误，不得覆盖已有文件。

## 联动会话（模型工具）

1. 在联动工作区里新建会话，问模型「这个联动工作区的远端根目录是什么」→ 它应调用 `linked_workspace` 的 `list`/`info`。
2. 让它读/改一个远端文件 → 改动应出现在远端（右侧栏或 SSH 终端复核），镜像开启时 `.remote/` 同步更新。
3. 让它在非联动目录执行同一工具 → 应得到「当前会话不是联动工作区」的提示。
4. 工具 `sync` 现在启动后台任务并立即返回进度说明，前端设置卡片继续轮询。

## 文档编辑

1. 在目录右键「新建文件」输入 `demo.md` / `demo.docx` / `demo.xlsx` / `demo.pptx` / `demo.pdf`，应创建对应空白文档并在内容面板打开。
2. Markdown：编辑文本 → 保存 → 预览 → 导出 PDF；导出的 PDF 与 Markdown 同目录，中文正常。
3. DOCX：修改段落/表格文字 → 保存 → 重新打开内容仍在。
4. XLSX：切换工作表、修改单元格 → 保存 → 重新打开值仍在。
5. PPTX：切换幻灯片、修改文本框 → 保存 → 重新打开文字仍在。
6. PDF：翻页、旋转/删除页面、修改标题/作者 → 保存 → 重新打开生效。
7. 以上操作在本地目录与远端（联动工作区）文件上都应可用；Office/PDF 需要 Python 3 + python-docx/openpyxl/python-pptx/PyMuPDF。

- 新建一个空白联动工作区会话：右侧栏开始页应出现「联动工作区目录」，打开后目录面板正常显示。

## 图片 / CSV 预览与移动（0.8.0）

1. 本地目录与远端目录各放一个 PNG、一个 SVG、一个 JPG：单击文件应在内容面板显示图片，状态栏显示 MIME 与大小；损坏图片显示错误提示而不是空白。
2. 打开 CSV/TSV：默认显示表格，第一行作为表头；超过 1000 行或 80 列时显示截断提示；点「源码」可切换编辑器并保存，表格模式下保存按钮禁用。
3. 含引号、逗号、字段内换行的 CSV 应正确分列；TSV 按制表符分列。
4. 右键文件/文件夹 →「移动到…」：在本地目录内可移动到当前目录的任意子目录，在远端目录内可移动到当前远程工作区根目录或子目录。
5. 移动后目录树与内容面板一致；已打开的旧标签关闭，已修改未保存的文件阻止移动并提示先保存。
6. 目标目录已有同名文件时提示冲突（409），不覆盖；文件夹不能移动到自身或其子目录。
7. 移动选择器不能浏览到当前工作区/本地目录之外，根目录本身不可作为被移动项。

## 图片缩放与网页预览（0.8.1）

1. 打开 PNG/SVG：图片默认适应窗口；点「适应窗口」重新适配，「1:1」恢复原始像素。
2. 点 `−` / `+` 时缩放比例按 20% 步进，状态栏百分比同步；`Ctrl/Cmd + 滚轮` 可连续缩放，最小 5%、最大 800%。
3. 放大后图片区域出现滚动条，可查看四周；缩小后图片保持居中，不出现拉伸变形。
4. 本地与远端各打开一个 `.html`/`.htm`：内容面板以 iframe 渲染页面，状态栏显示 HTML、大小和「网页脚本已禁用」。
5. HTML 内联样式与静态标签正常显示；页面内脚本不执行，链接不会跳出 DSH 主界面。
6. 读取失败的 HTML（权限/过大/二进制）显示错误提示和重试按钮。

## 安全、分页与可访问性（0.8.2）

1. **预览链接净化**：在本地或远端放一个 Markdown 文件，内容含 `<a href="jav&#9;ascript:document.title='X'">click</a>` 与 `[example](https://example.com)`；预览后点第一个链接：页面不应跳转、标题不变、DSH 界面不被替换；第二个链接仍指向 `https://example.com`。`vbscript:`、`file:`、`data:text/html`、`data:image/svg+xml` 链接同样应被移除。
2. **大目录分页**：造一个 20 000 项的目录（`1..20000 | % { New-Item -ItemType File "f$_.txt" }`），在目录树展开它：应只出现 500 行和「加载更多（剩余 19500 项）」，页面不卡顿、可滚动、可点其他文件；点「加载更多」追加 500 行并更新剩余计数，滚到底部后可继续加载。
3. **键盘操作**：Tab 到目录树行应看到明显焦点环；聚焦树行时 `←` 收起、`→` 展开目录；读屏应能听到 treeitem 层级与展开状态。
4. **添加工作区弹窗**：打开后焦点直接在第一个输入框；连按 Tab 焦点在弹窗内循环，不会跑到背景页面；`Esc` 关闭弹窗。
5. **大文件窥视**：打开一个 >2 GB 的本地文件（只读预览）：应显示「文件过大，仅显示前 512 KB」而不是报错或长时间卡住；内存不随文件大小增长。
6. **复制上限**：在远端复制一个 >64 MB 的文本/二进制文件：应提示「超过 64 MB，无法复制」，目标目录不得出现被截断的副本。
7. **非空目录删除（工具）**：让 agent 用 `linked_workspace` 的 `delete` 删除一个含文件的远端目录：应递归删除成功，不再报 SFTP `Failure`。
8. **Excel 截断提示**：打开一个 >200 行或 >40 列的 xlsx：表格上方应出现「仅显示前 200 行 × 40 列」；工作表超过 20 个时出现「仅显示前 20 个工作表」。

## 分页续修与预览覆盖（0.8.3）

1. **预览覆盖层**：放一个 Markdown 文件，内容为 `<div style="position:fixed;inset:0;z-index:99999;background:#fff;padding:24px">FAKE-LOGIN-PAGE</div>` 加一行普通文字；预览后不应出现全屏白底覆盖层，`div` 上不应残留 `style` 属性，页面其余部分照常可点。
2. **加载更多不被刷新清空**：在本地树展开一个 >500 项的目录，点「加载更多」后**静置 10 秒**（跨过两次 4 秒刷新）：行数与剩余计数应保持不变，不回退到 500 行。
3. **隐藏文件下的分页**：目录中同时放 300 个 `.hidden*.txt` 与 600 个 `visible*.txt`；先关闭「显示隐藏的文件」再展开该目录，点「加载更多」：可见条目不应重复、不应遗漏，最终数量为 600，剩余计数归零。
4. **目录选择器上限**：进入一个含 600+ 子目录的父目录：列表面板最多显示 500 项，并提示「目录项过多，仅显示前 500 项；可直接在输入框中输入路径」；在输入框直接键入子路径仍可选择。
5. **翻页性能**：对 20 000 项的远端目录连续点两次「加载更多」：第二次起应明显快于首次（5 秒内命中列表缓存），且界面不卡顿。
